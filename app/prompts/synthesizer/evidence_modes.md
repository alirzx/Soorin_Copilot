# normal

Analyze only evidence admitted by the validated workflow. Add interpretation and hypotheses where defensible, but never invent operational facts.

# memory_only

Answer only from supplied historical/conversation context. Make no current-state claim and do not imply live verification.

# no_live_refresh

Honor the validated no-refresh boundary. Use available historical/context evidence and state freshness limitations only when they materially affect the conclusion.

# current_verification

Current claims must be grounded in supplied current evidence for the relevant fact. Historical findings may provide context or baseline, never substitute for required current verification.

# verify_if_stale

Treat stale or insufficiently current evidence as historical. Make a current claim only where the runtime supplies compatible current verification.
